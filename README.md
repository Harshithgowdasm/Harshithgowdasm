#### 🚀 Projects & Research

- 🧠 **[RL Gait Control for Petoi Bittle](https://github.com/Harshithgowdasm/opencat-gym)**: Trained quadruped for autonomous step climbing and gait generation using PPO, TD3 in sim-to-real setting.
- 🌀 **[Gaussian Process Model Predictive Control](https://github.com/Harshithgowdasm/GP_MPC)**: Probabilistic MPC using GPs with model uncertainty in MATLAB.
- 🧬 **[Graph-Based CAD File Complexity Classification](https://github.com/Harshithgowdasm/3D_STEP_file_analysis)**: Used GNNs to extract, classify and optimize CAD data from STEP files.
- ⏱️ **[Biosignal-Based Emotion Recognition](https://github.com/Harshithgowdasm/bbdc24-mlbananas)**: ML pipeline for multimodal smartwatch data for emotion/context detection — *Bremen Big Data Challenge 2024*.
